# WhatKey Local Log

Dated entries recording what was tried, what happened, and what was decided.
Conventions are inherited from `research/whatkey/log/README.md` unchanged: one
file per session or decision (`YYYY-MM-DD-NN-short-slug.md`), append-only,
copy-pasteable commands in Setup, numbers with pins, negative results included,
and a Plain-English reading section when an entry is statistics-heavy.
